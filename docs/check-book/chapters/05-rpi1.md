# Raspberry Pi 1 / Zero

Плата: BCM2835, 1 × ARM1176 (ARMv6), 256–512 МБ. Консоль — `ttyAMA0`, гребёнка
(6 — GND, 8 — TXD, 10 — RXD), 115200. Прошивка `rpi1`. Все результаты — **ожидаемые**.

## 1. Загрузка

Прошивка GPU ничего не печатает в UART. На HDMI на мгновение появляется цветной
экран прошивки, затем:

```text
U-Boot 2026.07 (…)
Model: Raspberry Pi Model B+
…
Retrieving file: /zImage
Retrieving file: /bcm2835-rpi-b-plus.dtb
Starting kernel ...
Linux version 7.2.9-rpi1 …
raspberrypi login:
```

| Проверка | Норма |
|---|---|
| dtb по модели | B+ → `bcm2835-rpi-b-plus.dtb`, B rev2 → `bcm2835-rpi-b-rev2.dtb`, Zero → `bcm2835-rpi-zero.dtb`; `printenv fdtfile` в U-Boot |
| U-Boot стартовал | если в UART тишина, а на HDMI цветной экран остался — прошивка не нашла dtb под старым именем `bcm2708-rpi-*.dtb` (первая книга, глава 13) |

## 2. Светодиоды

```text
# ls /sys/class/leds/            ACT, PWR
```

ACT мигает «сердцебиением» (триггер `heartbeat`).

## 3. Ethernet (B, B+)

Ethernet висит на USB-хабе (LAN9512/9514):

```text
# dmesg | grep smsc95xx
# ip -4 addr show eth0
```

У A/A+ и Zero Ethernet нет.

## 4. HDMI и клавиатура

Лог и приглашение на мониторе (`tty1`), USB-клавиатура работает. Драйвер VC4 встроен.

## 5. USB

Флешка: `dmesg | tail`, `mount /dev/sda1 /mnt`. У B/B+ порты и Ethernet делят
один USB 2.0: при копировании по сети скорость ограничена.

## 6. GPIO17

Светодиод с резистором между контактом 11 (GPIO17) и 9 (GND):

```text
# gpio-blink /dev/gpiochip0 17 10 500
```

## 7. I2C1 (контакты 3 — SDA, 5 — SCL)

```text
# i2cdetect -y 1                 пакет i2c-tools
```

## 8. Датчики и частота

```text
# cat /sys/class/thermal/thermal_zone0/temp       BCM2835 thermal
# cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_cur_freq
```

## 9. Звук

```text
# aplay -l
```

**Ожидается** звуковая карта HDMI от VC4. Аналоговый выход 3,5 мм в mainline идёт через
драйвер staging `snd-bcm2835` (модулем) и может не появиться.

## Не работает по известным причинам

| Что | Почему |
|---|---|
| Wi-Fi Zero W | нет прошивки чипа в rootfs |
| `/proc/config.gz` | `IKCONFIG_PROC` выключен в `bcm2835_defconfig` |
| Overlay во время работы | `OF_OVERLAY` выключен (U-Boot overlay применяет) |
