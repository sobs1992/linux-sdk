# Если проверка не прошла

| Симптом | Что проверить | Где подробнее |
|---|---|---|
| Ничего в UART, плата «мёртвая» | скорость 115200, TX↔RX, общая земля, питание; у BBB — кнопка S2; у OGA — загрузчик во SPI | книга 1, гл. 11 |
| Мусор в UART | скорость; кто печатает (загрузчик ROM/SPI на 1,5 Мбод) | книга 1, гл. 11 |
| U-Boot есть, ядра нет | `bootflow scan -l`, `printenv fdtfile`, файлы на BOOT, `fdtoverlay_addr_r` при overlay | книга 2, гл. 9 |
| Ядро молчит после `Starting kernel` | `earlycon` в командной строке, адреса загрузки | книга 2, гл. 8 |
| `VFS: Unable to mount root fs` | `root=PARTUUID`, драйвер SD встроен, раздел записан | книга 1, гл. 10 |
| Нет приглашения | getty на нужной консоли, `console=` | книга 1, гл. 8 |
| Модули не грузятся | версия ядра и `/lib/modules`, полная перепрошивка | книга 2, гл. 7 |
| Параметр ядра не действует | включена ли опция Kconfig, которая его читает (пример — `fbcon=rotate`) | книга 1, гл. 14 |
| Устройство не появилось | `devices_deferred`, узел в DTS, драйвер в `.config` | книга 2, гл. 8 |
| Нестабильная работа | питание (блок не меньше 2 А, для Pi 4 — 3 А), нагрев, карта памяти | глава 2 |

!!! tip "Сначала — что изменилось"
    Самый быстрый путь к причине — сравнить с последней рабочей сборкой: журнал UART,
    `dmesg`, `board-check.sh`, `git log` в SDK и сабмодулях. Поэтому протокол испытаний
    стоит вести с первого дня.
