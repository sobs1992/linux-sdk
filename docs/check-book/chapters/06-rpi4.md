# Raspberry Pi 4 / 400

Плата: BCM2711, 4 × Cortex-A72, 2–8 ГБ (Pi 400 — 4 ГБ). Консоль на гребёнке —
mini-UART `ttyS1` (контакты 6, 8, 10), 115200. Pi 400: основная консоль — HDMI и
встроенная клавиатура. Прошивка `rpi4`. Все результаты — **ожидаемые**.

## 1. Загрузка

```text
U-Boot 2026.07 (…)
Model: Raspberry Pi 400 Rev 1.x            (или Raspberry Pi 4 Model B …)
…
Retrieving file: /Image
Retrieving file: /broadcom/bcm2711-rpi-400.dtb
Starting kernel ...
Linux version 7.2.9-rpi4 …
raspberrypi login:
```

| Проверка | Норма |
|---|---|
| dtb | `broadcom/bcm2711-rpi-400.dtb` или `-rpi-4-b.dtb`; прошивке нужен тот же файл в корне BOOT |
| UART молчит | `enable_uart=1` в `config.txt`, адаптер на контактах 8/10 |
| Ничего на экране и в UART | EEPROM показывает диагностический экран по HDMI — прочитайте сообщение |

## 2. HDMI и клавиатура Pi 400

Монитор — в порт с подписью **HDMI0** (прошивка и консоль выводятся на него). На экране — лог и приглашение,
встроенная клавиатура Pi 400 вводит текст (контроллер USB VL805 на PCIe, драйверы
встроены). Для Pi 4 B — любая USB-клавиатура.

```text
# dmesg | grep -i -E 'xhci|vl805|pcie'
```

## 3. Ethernet

```text
# dmesg | grep -i genet
# ip -4 addr show eth0
```

## 4. USB

Флешка в синий порт USB 3.0, затем в чёрный USB 2.0: оба должны определяться.

```text
# dmesg | tail                 new SuperSpeed USB device … (для USB 3.0)
```

## 5. Светодиоды

```text
# ls /sys/class/leds/         Pi 4 B: ACT, PWR; Pi 400: только PWR
```

## 6. GPIO17 и I2C1

```text
# gpio-blink /dev/gpiochip0 17 10 500
# i2cdetect -y 1               контакты 3 и 5; драйвер i2c-bcm2835 — модуль
```

## 7. Датчики и частота

```text
# cat /sys/class/thermal/thermal_zone0/temp
# cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_available_frequencies
```

Драйверы температуры и частоты (`bcm2711_thermal`, `raspberrypi-cpufreq`) — модули: если
файлов нет, проверьте `lsmod`. Под нагрузкой без радиатора Pi 4 нагревается до 80 °C
и снижает частоту.

## 8. Звук

```text
# aplay -l                     HDMI-звук через VC4
# speaker-test -D hw:0 -c 2 -t sine
```

## Не работает по известным причинам

| Что | Почему | Как включить |
|---|---|---|
| Wi-Fi, Bluetooth | драйвер `brcmfmac` есть, но нет файлов прошивки чипа: в `dmesg` будет ошибка загрузки прошивки `brcmfmac` | `BR2_PACKAGE_BRCMFMAC_SDIO_FIRMWARE_RPI=y`, `_WIFI=y`, `_BT=y` в defconfig платы |
| ACT на Pi 400 | на плате его нет | — |
