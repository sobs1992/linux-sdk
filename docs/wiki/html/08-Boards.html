ODROID-GO Ultra (ogu) — основная игровая платформа

  • Загрузчик. Свой FIP (BL2/BL30/BL31 Amlogic + mainline U-Boot) с сектора 1; на eMMC записан (make flash-emmc, Vol+ при включении показывает eMMC как USB-диск — патч U-Boot 0012). Экран зажигает уже U-Boot (патчи 0003–0010: DSI, панель ST7701). 17 патчей U-Boot всего. Шаги загрузки печатаются на экран.
  • Диски. eMMC: система + /data до конца; все игры — SD exFAT GAMES.
  • Быстрая загрузка ~3,7 с до меню: кэши в arch_cpu_init, таблица phandle, BOOTDELAY=0, ядро без чужих платформ (Image 22 МБ), quiet, панель не переинициализируется (ядро 0026), coldplug параллельно.
  • Гибернация. Короткое нажатие питания → экран гаснет → через 10 с pm-hibernate в /data/hibernate.swap (1,5 ГиБ). Ядро 0028 уносит GPU-буферы в swap (DOOM 3 помещается), 0029 возвращает клоки модулей после реального выключения. Без места — pm-suspend (s2idle). Пробуждение из deep sleep по кнопке питания через BL30 — не решено (BL301 нужно пересобирать).
  • Питание. Два PMIC: RK818 (батарея, USB-C) и RK817 (загрузочный кластер, звук, кнопка питания). Выключение как у Hardkernel (ядро 0016): плата сама включается от USB, U-Boot (патч 0001) ждёт кнопку при зарядке. Покой 889 мА с подсветкой / 682 мА без — аппаратный пол; cpuidle вешает загрузку (BL31).
  • Часы. RK817 отстаёт на 14 %, время — из RK818 (rtc-clock, S31clock); зон нет, хранится UTC. Батарея после сброса PMIC — ядро 0031.
  • Перезагрузка. DEV_OFF_RST RK818 перед reboot (ядро 0017) и SD на 50 МГц в U-Boot (0002) — иначе U-Boot минутами не видел карту.
  • Аппаратный H.264 — свой V4L2-драйвер meson-venc (HCODEC, внешний модуль) для трансляции.
  • Bit-42. Под нагрузкой GPU чтение иногда отдаёт бит 42 неверно (кэш врёт, DRAM права) — аппаратная особенность этого экземпляра. Ядро 0025 ограничивает GPU 666 МГц: на стенде 0 ошибок, на 800 МГц — ошибки и паника DOOM 3. Стенд — круглая кнопка «Стресс-тест» в меню (фур-донат + детекторы MEM/GPU/CPU/TEX).
  • USB-A — хост: клавиатура, мышь, Wi-Fi-адаптеры (Realtek, MediaTek, Atheros, Ralink модулями), датчик движения на Pico (ICM-20948) как гироскоп.
  • Звук — S30audio ставит маршрут DPCM; axg-sound-card не выгружать.

ODROID-GO Advance (oga)

  • Гибридный образ: SPI miniloader (Black Edition) или открытая цепочка TPL/SPL/TF-A. Ревизия платы — по SARADC, три dtb (go2, go2-v11, go3).
  • Ядро: 3 патча — делители I2S (без них звук вдвое медленнее), перезагрузка через RK817, опрос стика раз в 10 мс со снап-бэком.
  • Быстрая загрузка ~5 с: BOOTDELAY=0, ядро без лишнего, quiet, mdev в фоне, bare_app S06 сразу после /data.
  • Аппаратный H.264 — свой драйвер rk-vepu-h264 (VEPU2 PX30; Hantro в ядре выключен): 960×640 за 8–9 мс, стрим Героев 30 fps при ~10 % CPU.
  • Диски: всё на SD — p3 data 1 ГБ, p4 GAMES FAT32 до конца; образ с играми — games-image.py без --card.
  • Wi-Fi ESP8089 (внешний модуль). Доступ — UART (oga-serial.py) или ssh.
  • Игры: Герои (VCMI, окно 960×640 вдвое больше экрана, лупа), Doom, Half-Life (программный рендер). Wine нет — процессор слабый.

BeagleBone Black, Raspberry Pi

Опорные платы без экрана и геймпада: проверяют общность SDK. BBB грузится сначала с eMMC (S2 при включении — с SD). RPi не читает raw-секторы: прошивка GPU → config.txt → u-boot.bin; dtb лежат и под именами прошивки, и mainline. На всех — DHCP на eth0 и dropbear (пароль root задать passwd).

Добавить плату

Чек-лист — docs/adding-a-board.md: configs/<fw>_defconfig, board/<плата>/ (defconfig Buildroot, фрагменты ядра и U-Boot, патчи, boot/), блобы через BOOTFW_*/AML_FIP_* с хешами, и если есть экран с кнопками — платформа в bare_app (src/platforms/<плата>.c, PLATFORM_<ПЛАТА> в Kconfig, configs/<плата>_defconfig приложения). Оценка RG552 (RK3399) есть в памяти проекта: mainline почти полный, нужны панель, плата U-Boot и мультиплексор джойстика.
