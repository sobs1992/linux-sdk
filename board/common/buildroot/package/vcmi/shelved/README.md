# Отложенные патчи VCMI

Здесь лежат патчи, которые пакет `vcmi` не применяет: Buildroot берёт только `*.patch`
из каталога пакета, подкаталоги он не смотрит. Чтобы вернуть патч, перенесите его в
каталог пакета под следующим номером и проверьте, что он ложится строго (`patch -F0`):
Buildroot нечёткое совпадение не допускает.

## fit-view-taken-down-in-linear-light.patch

Вид «fit» для ODROID-GO Ultra (`BARE_APP_VCMI_FIT=1`): весь экран игры на 854×480
сразу, без прокрутки за курсором. VCMI рисует экран 854×600 вдвое больше и уменьшает
его в линейной яркости; текст рисуется TrueType-шрифтами прямо в сетке пикселей
дисплея, L1 включает лупу 1:1 с оригинальными растровыми шрифтами.

Отложен 2026-11-04. Пакет вместо него использует 0008: экран 1:1, видна часть экрана
по положению курсора.

Состояние на момент откладывания:
- сделан на 0001–0008 и 0010, ложится на них строго;
- работал на плате (~58 кадров/с), но не доведён: bare_app не умеет его включать
  (на плате его включала временная обёртка `vcmiclient`, выставлявшая переменную);
- нужен шрифт NotoSerif-CondensedMedium (github.com/notofonts, OFL) в
  `Mods/vcmi/Content/Data` — пакет его не ставит, на плату его копировали руками.
