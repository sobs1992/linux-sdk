Состояние приставки

Установка игр

Перетащите сюда установщик игры из GOG (файл setup_….exe вместе со всеми его файлами .bin) — файлы запишутся в папку install на карте игр. Потом нажмите «Установить» у игры в списке ниже. Папку игры, уже установленной на компьютере, удобнее скопировать через «USB-диск» на приставке.

Перетащите файлы сюда или

В папке install

Файлы Windows для игр (папка redist)

Некоторым играм нужны файлы, которых нет в их установщике (список «Не хватает файлов» у игры выше). Положите их сюда. Библиотеки DirectX приставка берёт сама из установщиков GOG; если их там нет, скачайте с сайта Microsoft пакет DirectX End-User Runtimes (June 2010) (файл directx_Jun2010_redist.exe) и перетащите его сюда как есть.

Сохранения

    
Копия игры — один файл .zip с её сохранениями, настройками управления и
      правками. Скачайте её на компьютер, чтобы сохранения пережили перепрошивку, или
      загрузите её на другой приставке («Загрузить копию», затем «Восстановить»). Копии лежат
      на карте игр в папке backups (без карты — в памяти приставки); после каждой игры
      приставка сама делает копию, если сохранения изменились, и хранит три последних.

Отчёты

    
Отчёт — один текстовый файл о том, что стоит на приставке и что в ней
      происходило (без паролей Wi-Fi и ключей). Его приложите к сообщению об ошибке.
